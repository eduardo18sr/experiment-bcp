## Idea
El documento metodológico declara de forma explícita el perímetro de aplicación del modelo: a qué segmento se aplica, a qué producto, por qué canal y durante qué vigencia.

## Por qué funciona
Un perímetro implícito o incompleto deja abierta la pregunta de si el modelo se está usando fuera de lo que se desarrolló y validó. Declarar los cuatro elementos permite contrastar el uso real contra el diseño y detectar extensiones no validadas.

## Cuándo usarlo
- Cuando el documento describe el modelo pero no dice para qué canal o por cuánto tiempo aplica.
- Cuando el mismo modelo se usa en más de un producto.
